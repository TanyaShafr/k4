# Дело о чужом входе · 4 класс

Интерактивная игра-расследование: шесть улик, три попытки с подсказками, бонусные задания и живая рейтинговая таблица.

## Запуск

Откройте `index.html` в браузере или разместите весь проект на статическом хостинге. Папка `assets` должна находиться рядом с `index.html`. Сборка и установка зависимостей не требуются.

1. Учитель выбирает **Я учитель → Создать занятие** и показывает код на доске.
2. Ученики открывают ту же страницу, указывают класс, имя и код.
3. Учитель открывает задания и переключает улики.
4. Кнопка **Рейтинг класса** показывает обновляемую таблицу результатов.

Для подключения по коду и синхронизации нужен интернет. В исходнике отсутствует список учеников 4 класса: вход по классу и имени.

## Задания

Лаборатория сообщений, шифровальный диск, проверка источника фотографии, защита данных в анкете, хронология событий и поиск подмены символа в адресе.

На каждую улику — три попытки, после ошибки появляется подсказка. За основное задание можно получить до 10 баллов, за бонусное — до 5; максимум 90. Ответы перемешиваются, порядок сохраняется при повторной попытке. В финале — три разные PNG-совушки настроения.

Все иллюстрации сохранены в PNG; главные герои исходного урока сохранены. Игровые адреса в заданиях являются учебными примерами.
